# Developer Journal — Sukrat Agrawal

**Role:** Frontend + Backend Integration + Documentation  
**Project:** Academic Research Navigator (ARN)

## What I worked on

- Worked on the frontend interface of ARN.
- Worked on the search interface and presentation of search results.
- Worked on connecting the frontend with the FastAPI backend.
- Connected frontend actions with the required API endpoints.
- Helped display backend results such as resource title, author, score, subjects and relevance explanation.
- Contributed to project documentation and explained the working of different parts of the system.

## Results

- Frontend was connected to the working backend search API.
- Search results received from the backend could be displayed in the UI.
- Resource information and relevance information could be shown to the user.
- Contributed to the final project documentation.

## What I learned

- How a frontend communicates with a Python backend.
- How API requests and responses are used in a web application.
- How JSON data returned by the backend is used to update the interface.
- How the different parts of a project need to work together instead of being developed separately.

## Challenges faced

- Understanding how the frontend and backend communicate with each other.
- Making sure the data returned by the backend was displayed correctly in the frontend.
- Keeping the documentation consistent with the actual implementation.

## Contribution to ARN

My main contribution was making the user interface and backend work together as one application, while also helping document the project.
