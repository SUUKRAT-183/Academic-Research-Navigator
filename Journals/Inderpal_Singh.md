# Developer Journal — Inderpal Singh

**Role:** Dataset Scraping + Preprocessing + Documentation  
**Project:** Academic Research Navigator (ARN)

## What I worked on

- Worked on collecting the dataset required for the ARN prototype.
- Worked on scraping and gathering resource information.
- Cleaned and organized the collected data.
- Worked on preprocessing the dataset so that it could be used by the search system.
- Helped prepare the catalogue data used by the project.
- Contributed to documenting the dataset preparation process.

## Results

- Collected the resource information needed for the prototype.
- Prepared the data in a structured format for use by the application.
- Removed or handled data inconsistencies during preprocessing.
- Provided a usable catalogue for the search and retrieval part of ARN.

## What I learned

- How data is collected from an online source.
- Why raw scraped data needs cleaning before it can be used.
- How fields such as title, author, year, subjects and abstract need to be organized consistently.
- How the quality and structure of the dataset affects a search system.

## Challenges faced

- Scraped data was not always consistent in format.
- Some records contained missing or incomplete information.
- The collected data needed cleaning and restructuring before being used by the prototype.

## Contribution to ARN

My main contribution was preparing the dataset that the ARN prototype searches through. The scraping and preprocessing work provided the resource catalogue needed by the rest of the system.
